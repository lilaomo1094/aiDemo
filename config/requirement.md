# 登录功能测试需求

## 1. 功能概述
商户端登录页面需要支持手机号 + 密码登录。

## 2. 页面入口
- URL: `https://merchant-dev.nexuscube.cn/#/login`

## 3. 测试要点

### 3.1 正常登录
- 输入正确的手机号 `13411985758`
- 输入正确的密码 `888888`
- 点击登录按钮
- 预期：登录成功，页面跳转至商户后台首页

### 3.2 异常登录
- 手机号为空时点击登录
- 密码为空时点击登录
- 手机号格式错误（如少于 11 位）
- 密码错误
- 预期：页面给出明确的错误提示，不跳转

### 3.3 页面元素
- 手机号输入框应可正常输入
- 密码输入框应可正常输入
- 登录按钮应可点击
- 页面应展示登录标题或品牌标识
